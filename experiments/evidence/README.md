# Compact experimental evidence

These files are exact proposal exports and descriptive summaries from the supplied local run archives. Each lot includes original blind proposals, a condition-labelled proposal table, a recorded result, a reduced design and hashes of original source files. No provider credentials, raw transport dumps, caches, journals or vaults are published here.

| Lot | Proposals | Meaning |
| --- | ---: | --- |
| creative-preview-003 | 60 | Fresh encoding and sleep, five conditions, guarded task-blind readout |
| creative-replay-003 | 72 | Fixed-selection readout experiment using preview-002 states |
| creative-replay-004 | 72 | Structured memory delivery using replay-003 readouts |
| memory-influence-005 | 72 | Frozen-pool grounding reevaluation; most work reused from earlier lots |

The 276 exported rows are not 276 independent lives, and reused influence rows are not new generations. Do not pool the lots into a single effectiveness estimate.

`provenance.json` hashes refer to the original complete run files before compact export. `SHA256SUMS` covers the publication files. The export is sufficient to inspect/rate the recorded answers, but not to resume collection or reconstruct every source memory. Historical full archives are retained locally outside the proposed source commit.

Give independent judges only a lot's `blind-proposals.json`, its task instructions and separate blank forms. Do not give them this directory's labelled files, pipeline scores or showcase examples before judging.

No completed independent blind ratings are included. The source discussion's earlier single unblinded review is exploratory and is deliberately not presented as an established benchmark score.

Dataset attribution: source conversations come from the official LoCoMo release by Snap Research: https://github.com/snap-research/locomo . These are conversation-derived creative tasks, not official LoCoMo benchmark scores. SelMem's MIT license does not relicense third-party dataset material. Model outputs are recorded observations, not verified real-world solutions.
